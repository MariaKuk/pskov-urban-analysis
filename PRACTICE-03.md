# Практика 3: приложение для размещения школ в Пскове

**Кукатова Мария Владимировна.** Продолжение проекта практики 2, 24.11.2026.

[Скачать приложение, исходный код, данные, результаты и проверки](school-placement.zip).

Распакуйте архив в корень этого проекта. Появится папка `school-placement`. Исходные файлы практики 2 менять не нужно.

**Windows:** установите Python 3.12 x64 с Python Launcher, распакуйте архив, откройте `school-placement/setup-windows.cmd`, дождитесь успешной проверки, затем откройте `start-windows.cmd`. Браузер откроется автоматически. Интернет нужен только для первоначальной установки зависимостей.

[Автоматическая проверка на Windows](https://github.com/MariaKuk/pskov-urban-analysis/actions/workflows/windows.yml).

**macOS:** из корня проекта с настроенным окружением практики 2:

```bash
.venv/bin/python school-placement/server.py
```

Откройте **http://127.0.0.1:8766/**. В папке приложения есть `README.md` с инструкцией для другого компьютера и `start.command` для macOS. Приложению нужны Python 3.12, BlocksNet 1.0.0a9 и CBC; интернет и платные сервисы при работе не нужны. Это приложение с локальным расчётом в Python, а не статическая HTML-карта.

В интерфейсе: ручное размещение одной или нескольких школ, полный автоматический перебор кварталов для одной школы, карта «до / после / изменение», карточки кварталов, сравнение сценариев, рейтинг, CSV-экспорт и сброс.

Расчётная территория — **781 квартал** практики 2, согласованная пользователем. Ещё 152 квартала города показаны серым и не включены в модель.

| Вариант | Сокращение дефицита | Остаточный дефицит | Обеспеченность |
|---|---:|---:|---:|
| Исходное состояние | — | 12 651 | 44,43% |
| А: 600 мест в №127 | 600 | 12 051 | 47,07% |
| Б: по 300 мест в №127 и №295 | 600 | 12 051 | 47,07% |
| В: 600 мест в №2, одном из лучших вариантов | 600 | 12 051 | 47,07% |

Проверены **781 из 781 вариантов**, ошибок нет. **756 кварталов равноценны по основному критерию**, включая №127. №2 показан как один из лучших, а не как единственный оптимальный. При пороге времени 10 минут сценарии А и Б уже дают разные результаты; это ограничение подробно разобрано в отчёте.

Внутри архива: `REPORT.md`, `QUALITY_REPORT.md`, предварительный план `analysis-plan.json`, проверенные входы `data/`, результаты `results/`, протоколы `audit/`, весь исходный код и контрольные суммы `release-manifest.json`.

Код и расчёты выполнены с помощью Codex; ручные кварталы предложены по исходному дефициту и согласованы пользователем до автоматического поиска. Ограничения: модельное население и вместимость, автомобильная доступность, неполное покрытие города, отсутствие проверки земельных участков. Статус проверки — PASS_WITH_LIMITATIONS.
