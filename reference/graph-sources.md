# Источники готовых графов

Проверено 2026-11-23. Статус: каталог и оглавление проверены, графы не скачивались.

## Harvard Dataverse

- Набор: [Global Urban Street Networks GraphML](https://doi.org/10.7910/DVN/KA5HJ3).
- Автор: Geoff Boeing. Архив России: `russia-RUS_graphml.zip`.
- Файл Dataverse: 10962604, размер 61 824 517 байт.
- [Прямая загрузка архива России](https://dataverse.harvard.edu/api/access/datafile/10962604).
- MD5 опубликованного архива: `7e180746abdbfd50343a4b794278c3c6`.
- [Методика и код автора](https://github.com/gboeing/street-network-models).
- Это графы автомобильных улиц по границам городских ареалов GHSL;
  граница графа может отличаться от административной границы города.

Оглавление получено HTTP Range-запросом к последним 128 КиБ архива.
Сохранены только названия файлов: `russia_graphml_file_index.json`.

Подтверждённые примеры:

| Город | Файл в архиве |
|---|---|
| Миасс | `russia-RUS/miass-7109.graphml` |
| Псков | `russia-RUS/pskov-440.graphml` |
| Великий Новгород | `russia-RUS/veliky_novgorod-1092.graphml` |
| Петрозаводск | `russia-RUS/petrozavodsk-1311.graphml` |
| Пушкин | `russia-RUS/pushkin-725.graphml` |
| Колпино | `russia-RUS/kolpino-852.graphml` |

Именованных файлов Kingisepp/Sortavala нет. Наличие нужного покрытия
в файлах `unnamed` не проверено. Наличие имени в каталоге само по себе
не доказывает полное покрытие выбранной административной территории.

## OpenStreetMap через OSMnx / IduEdu

[IduEdu: построение графов](https://iduclub.github.io/IduEdu/api/high_level.html)
описывает получение дорожной или пешеходной сети из OSM и создание графа.
Это построение, а не скачивание заранее опубликованного GraphML. Для строгого
соответствия текущему тексту практики такой вариант требует уточнения.
Документация относится к новой версии IduEdu; в проекте установлена версия
0.4.1 как зависимость BlocksNet, поэтому код нужно адаптировать отдельно.
