# Исправления при фактическом запуске

## 2026-11-23 — доступ к OSM

Первый запуск остановлен на загрузке дорог: основной Overpass API возвращал HTTP
406, а запрос из OSMnx ожидал ответ. Граница Пскова успешно получена и сохранена.

Выбран резервный сервер https://ovp.dresel.systems/api/interpreter с данными Европы,
указанный в https://wiki.openstreetmap.org/wiki/Overpass_API . Малый проверочный
GET-запрос подтвердил наличие школьных объектов в Пскове. Полнота данных проверяется
основным запуском, а не этим тестом. Дата базы сохраняется из `osm3s` ответа.

Вместо длинного POST-запроса используется компактный GET по охватывающему прямоугольнику.
Фильтры тегов исходного примера сохранены. OSMnx 2.2.0 обрабатывает ответ и фильтрует
объекты по точной границе города. Сырые JSON-ответы сохраняются без изменений рядом
с GeoJSON; ошибки или замечания о неполном ответе останавливают расчёт.

Первый запуск и ноутбук с ошибкой сохранены в журнале и локальной резервной копии.
Изменение касается транспорта запроса, не перечня метрик или выбора территории.

## 2026-11-23 — область транспортных расчётов

Готовый граф: 1264 узла, 3140 направленных рёбер. В городской границе получено
933 квартала; у 143 расстояние до ближайшего узла больше ранее заданного порога
1000 м (максимум около 5,36 км). Поэтому первоначальная проверка остановила запуск.
Схема покрытия сохранена в `graph-coverage-first-run.png`.

По результату проверки входных данных, до расчёта обеспеченности, определена
транспортная область: ближайший узел принадлежит крупнейшей сильно связной
компоненте и расстояние привязки не превышает 1000 м. Основная компонента содержит
1233 узла. Направления, рёбра и порог не исправляются ради результата; граф не
достраивается. Разбор покрытия не подтверждает отсутствие физических дорог вне
этой области — там недостаточно данных выбранного готового графа.

Все 933 квартала сохраняются для плотностей, населения, вместимости и морфотипов.
Матрица, обеспеченность и среднее время рассчитываются только внутри объявленной
транспортной области. Вне неё транспортные показатели отсутствуют (не ноль).
Доли и средние транспортных показателей нельзя распространять на весь город.
В манифесте сохранены все включённые ID, площадь, оценка населения и вместимость.
Это исследовательское изменение пространственного охвата после проверки источника,
отдельно от административной границы Пскова. Для полного города нужен более полный
готовый граф или отдельно согласованное построение сети.

## 2026-11-23 — очистка школьных объектов и численная проверка

Исключены по тегам/названиям OSM: центр внешкольной работы «Патриот»
(node:1192521260), футбольная школа «Стрела» (node:1218125444, sport=soccer),
кибершкола (node:12728147801). У школы №12 оставлено именованное здание,
безымянная включающая территория way:293275088 сохранена среди исключённых,
чтобы не учитывать одно учреждение дважды. Названия нормализованы удалением
скобочного уточнения: точка «Псковский Педагогический Комплекс (бывш. школа №26)»
внутри одноимённого полигона теперь считается дублем. Сырые данные не изменены.
Это содержательная очистка после просмотра входных данных; официальный реестр
общеобразовательных организаций не использован. Специальные школы сохранены.

Итог: 41 школьный объект, 40 вместимостей восстановлены по 250 мест.
Доля обеспеченного модельного спроса внутри транспортной области после очистки
составляет 44,3893%. До очистки результат был 51,0466%; прежнее значение не
используется в итоговом дашборде. Изменение показывает чувствительность к качеству
каталога объектов и не интерпретируется как изменение реальной ситуации в городе.

При вычислениях на Mac появились предупреждения matmul в численной библиотеке.
Вспомогательные средние переведены на явное суммирование. Среднее время независимо
сверено через math.fsum, 24 маршрута — через NetworkX, все назначения KMeans —
с квадратами расстояний до центроидов без BLAS. Расхождений за допусками не найдено.

## 2026-11-23 — повторная проверка по требованию пользователя

Обнаружены два повторных физических контура зданий с совпадающими типами и этажностью:
way:106873493 / way:705720780 (жилое пятиэтажное здание с вариантами углового адреса)
и way:704756070 / way:706192757 (неуточнённое здание). В каждой паре оставлен первый
объект; исключённые исходные записи сохранены в buildings_exact_duplicates.geojson.
Повторный жилой контур давал лишние 176 человек в модели. Предыдущие результаты
сохранены в reference/audit-before-building-dedup; исправленные расчёты выполнены заново.

В аудит добавлена проверка точных дублей геометрии и хешей входов. Сборщик HTML теперь
отказывается использовать устаревший аудит, если данные изменились. В манифесте
перечисляются только аналитические выходы, чтобы повторный запуск не включал старый
дашборд и старую сводку в контрольные суммы нового исследования. Ограничение Python
в pyproject.toml уточнено до проверенной версии 3.12 (SciPy и NetworkX требуют >=3.12).
В автономный HTML включён полный текст лицензии Leaflet.

Большой развёрнутый buildings.geojson (81 МБ) исключён из Git: он воспроизводится
из сохранённого buildings.overpass.json. Расчётный buildings.geojson и исходный JSON
сохранены. Местные файлы не удалялись; публикация не выполнялась.
